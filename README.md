# 🧮 Python GUI Calculator

Một ứng dụng máy tính desktop được xây dựng bằng Python và Tkinter,  
hỗ trợ thực hiện các phép tính số học cơ bản và một số hàm lượng giác thông qua giao diện đồ họa.

Dự án được xây dựng nhằm thực hành lập trình GUI với Tkinter, xử lý sự kiện và tổ chức chương trình thành các module riêng biệt.

## ✨ Features

- **Basic Operations:** Hỗ trợ cộng, trừ, nhân và chia.  
- **Trigonometric Functions:** Tính sin, cos, tan và cot theo đơn vị độ (degrees).  
- **Interactive GUI:** Giao diện với các nút bấm số, toán tử và hiển thị kết quả.  
- **Clear Input:** Xóa nội dung phép tính hiện tại.  
- **Advanced Math:** Mở cửa sổ riêng để sử dụng các hàm lượng giác.  

## 🛠 Tech Stack

**Python** – Ngôn ngữ lập trình chính;  
**Tkinter** – Xây dựng giao diện desktop;  

## 📂 Project Structure

- `main.py`: Khởi tạo cửa sổ và chạy ứng dụng.  
- `gui.py`: Thiết kế giao diện và xử lý các sự kiện nút bấm.  
- `calculator.py`: Xử lý phép tính và các hàm toán học.  

## 🚀 Getting Started

Yêu cầu Python 3.x và Tkinter (thường được tích hợp sẵn trong Python).

Chạy ứng dụng:

```bash
python main.py
```

## 💡 What I Learned

Thông qua dự án này, mình thực hành xây dựng giao diện desktop với Tkinter, xử lý sự kiện bằng callback và lambda,  
quản lý dữ liệu giữa các module và sử dụng thư viện `math` để triển khai các phép tính lượng giác.
